Work from the typed [[source-catalog]] and [[organization-catalog]] and the canonical Keller skills in `.agents/skills/`. The source PDFs, DBFs, transcripts, and customer-specific outputs remain in approved private storage, not this repo. The Polygres corpus is a separately selected, immutable evidence basis; no quote outcome or current manufacturing cost is implied by a historical printed price.

Use graph reads, `keller_polygres` for selected corpus evidence, and `keller_sources` for bounded read-only private-source inspection. Load [[Production RFQ retention and reviewed should-cost routing]] for the reusable production procedure and source contracts, not private evaluation diagnostics. For an internal order draft, `keller_quote` requires a JSON order request and named reviewer. An explicit corpus is mandatory for historical/mixed or evaluation-scoped requests; omit it for ALL-lines supported `unit_price`, `cost_plus` or `should_cost` requests, which need no database/export and retain honest null corpus provenance; its structured order/Markdown/review response and persisted artifact references are private. Return a finite historical or operator-supported line price as a clearly marked provisional proposal even when technical evidence is incomplete; preserve the uncertainty and keep the human review gate. Hold only when no defensible numeric basis exists, and request the concrete missing material/routing/rate evidence or reviewed estimate, rather than inventing a fallback. Preserve original RFQ/attachment bytes, units, evidence locators/hashes and unknowns using the manual retained-intake contract; text extraction does not verify geometry. Use the existing worksheet and gross-margin arithmetic for fully supported no-analog costs. Internal quote and order artifacts require named human review before customer communication or release. This workspace does not activate a scheduler, update a database, call a model provider on its own, send a customer quote, or establish the requested ≥90% completed-quoting accuracy.
