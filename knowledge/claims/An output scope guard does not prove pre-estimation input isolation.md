A response guard can correctly withhold an ineligible payload even when the backend already computed from an unfiltered corpus.
The time-bound backend reconstruction in [[Keller retained pre-estimation scope learning evidence]] links actual quote-call denials to persisted drafts containing ineligible analogs that the worker did not receive.
A successful probe whose chosen analogs happen to be allowed cannot distinguish that architecture from genuinely scoped input estimation.
The original preflight proposal therefore tests an excluded top analog and verifies the eligible persisted register, while retaining the output guard.
The later five successful calls reconciled exact eligible rows and scope/hash/count proofs, as preserved in [[Keller Git-pinned experimental reports 68c8201]].
That observed input-isolation recovery does not establish manufacturing equivalence, an adopted quote or operating-system sandboxing.
