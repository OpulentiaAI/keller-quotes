Supplied customer identity is part of request fidelity even when OrderRequest permits the field to be omitted.
The retained intake audit in [[Keller retained reissue learning evidence]] compares an RFQ containing customer_id with the actual quote-call input and returned request that omitted it.
Other workers using the same tool retained that field, so the observed omission was not tool-side stripping.
Correct arithmetic and a favorable judge assessment did not repair the identity mismatch.
The [[Keller Git-pinned experimental reports 68c8201]] keeps that invalid-fixture attempt and its mechanical failure rather than treating the independently accepted mapping proposal as proof of a recovered quote.
